# Contributing

Contributions are welcome when they improve the **rhetorical model**, not merely add more catchphrases.

## Good contributions

- a recurring sentence pattern with multiple examples;
- a new escalation mechanism;
- a correction separating authentic speech from a meme rewrite;
- a better minimal generation algorithm;
- examples demonstrating register differences.

## Source labels

When adding real-world source material, label it using the provenance classes in `references/provenance.md`.

Do not submit an unsourced meme line as an authentic quotation.

## Style principle

The central formula is:

```text
审问 → 定性 → 朴素证据 → 人民性 → 斗争化 → 历史必然性
```

“文亚体” should not degrade into generic shouting or indiscriminate insertion of “恶不恶？！”
