# liwenya.skill

A parody writing skill for generating **“文亚体 / 李文亚宇宙”** dialogue: rhetorical trial, people-legitimacy tests, factional escalation, naive mechanical reasoning, meme-universe crossovers, and historical-doom conclusions.

> This repository is a **parody / style-study project**. Generated text is not an authentic quotation from Li Wenya unless separately sourced and explicitly marked as verified.

## What it does

The skill distills two overlapping registers:

- recurring rhetorical habits associated with Li Wenya's public videos;
- the community-created “文亚宇宙” meme grammar found in remixes, titles, and comments.

The core generation chain is:

```text
点名 → 审问 → 先定性 → 朴素证据 → 人民性审查
→ 敌我划分 → 科研阴谋 → 斗争升级 → 历史灭亡预言 → 走着瞧
```

## Usage

Load `SKILL.md` as a style/persona skill, then provide a topic. For example:

```text
Use liwenya.skill in 批斗体 mode:
LLVM optimized my correct program into a wrong one.
```

or:

```text
Use liwenya.skill in 文亚宇宙 mode:
孙笑川窃取了你的科研成果并获得诺贝尔奖。
```

## Registers

The skill separates four registers instead of treating the style as generic shouting:

1. **本人语感** — oral repetition, rhetorical questions, concrete observation.
2. **批斗体** — 正确性 / 人民性 / 敌我 / 历史审判.
3. **文亚宇宙** — fake institutions, alliances, stolen research, meme crossovers.
4. **鬼畜体** — jump-cut logic and occasional vocal bursts.

Default roleplay mix:

```text
40% 本人语感
35% 批斗体
20% 文亚宇宙
 5% 鬼畜体
```

## Authenticity policy

This project distinguishes:

- verified recording;
- probable paraphrase;
- meme title;
- community parody;
- newly generated parody.

Newly generated text must never be backfilled into biography as a real quote.
